# Hi, I'm Ahmed Aziz Ben Ghorbel

I'm seeking **Support Engineer / Technical Support Engineer** roles. This portfolio brings together my academic and learning projects in Java, SQL, web applications, and connected devices.

I'm interested in understanding what happens between a user's action and the systems behind it: configuration, requests, database queries, permissions, and errors. These projects give you concrete code to inspect and discuss with me. They are academic and learning work.

## Projects to inspect

- **[Kindergarden Paydesk](https://github.com/AhmedAzizBenGhorbel/Kindergarden-Paydesk)** — A JavaFX payment-management application backed by MySQL. Start here for JDBC access, payment and receipt handling, administrator/personnel roles, activity logs, and local database backups. It connects a desktop interface to persistent data and makes configuration and recovery useful topics for discussion.

- **[Oracle DBA practical project](https://github.com/AhmedAzizBenGhorbel/oracle-dba-practical-project)** — An administration training lab covering instance inspection, startup states, tablespaces, users, privileges, and quotas. The phase scripts and original reports show the database questions being investigated. Administrative commands belong in a disposable training environment.

- **[Smart Door IoT](https://github.com/AhmedAzizBenGhorbel/smart-door-iot)** — ESP32 firmware and a Kotlin Android companion app exchange door and alarm states through Firebase Realtime Database. Inspect the shared values and configuration templates to follow how device, network, database, and app behavior fit together.

- **[Java client management](https://github.com/AhmedAzizBenGhorbel/gestioncommande)** — A servlet application using MVC, a DAO layer, JDBC, and MySQL. Follow a client operation from the web interface through the servlet to its database query to see the application's request flow.

- **[Byrsa Store database](https://github.com/AhmedAzizBenGhorbel/Byrsa-Store)** — An Oracle SQL store model with orders, products, payments, and deliveries. The table definitions, joins, aggregates, and views provide a small relational system to inspect and reason about.

- **[Laravel article CRUD](https://github.com/AhmedAzizBenGhorbel/laravel-article-crud-exam)** — A PHP/Laravel exam project with article forms, request validation, Eloquent persistence, and migrations. It offers another way to trace a form submission through a web application and its database.

- **Fundamentals:** C linked lists and memory management, Python input/file handling, Java collections and exceptions.
